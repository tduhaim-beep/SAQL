# Saudi government production hard gate
Government/customer production data must not be used until all applicable items are approved:
- Customer data classification
- Applicable NCA/NDMO/PDPL/CST/control mapping
- SaaS/CSP regulatory-role confirmation
- Production cloud/service qualification
- Data flow and residency map
- Third-party/subprocessor review
- Privileged MFA/access design
- Backup/restore evidence
- Vulnerability-management baseline
- Incident-response baseline
- Customer-specific security requirements
