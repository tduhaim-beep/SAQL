# Architecture Baseline — Pilot v2.0

- Web-based modular monolith.
- Single application deployable for Validation Pilot.
- PostgreSQL operational store.
- Domain-oriented modules; presentation/application/domain/infrastructure separation.
- Server-side business state and authorization.
- Public opportunity discovery/applications are in Pilot v2 scope; advanced marketplace ranking/recommendation is not.
- Training Journey Core is independent from Academic Overlay.
- Provider-specific services remain behind infrastructure adapters.
- Government production remains separately compliance-gated.

See `domain-map-v2.md`, `module-boundaries.md`, `AGENTS.md` and the implementation-control pack.
